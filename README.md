# 汽车直播话术生成器

面向汽车真人直播的轻量话术生成工具。

## 当前功能

- 输入品牌、车型、直播时长和核心主题
- 可选择停留、评论、关注、留资目标
- 可粘贴自己的行情/配置/文章素材，优先依据素材生成
- 自动生成：开场留人、车型选择、版本选择、费用逻辑、互动、自然上链接、循环留人和收尾衔接
- 一键复制完整话术
- 当前版本纯前端运行，不需要服务器和 API Key

## 使用

直接打开 `index.html` 即可使用。

也可以开启 GitHub Pages：仓库 Settings → Pages → Deploy from a branch → `main` / `(root)` → Save。发布完成后即可通过网页访问。

## 下一阶段

计划升级为 AI 版本：

1. 接入大模型 API，按素材生成真正的 30/60/90 分钟长篇口语稿。
2. 支持上传历史优秀直播稿，学习主播固定语言风格。
3. 增加话题模块库：车型对比、版本推荐、燃油/混动选择、行情、避坑、费用拆解。
4. 支持“尽量保留原文，只优化衔接”的改稿模式。
5. 对未经素材支持的实时价格、补贴、政策做显式提示，避免自动编造数字。

## 项目定位

目标不是生成泛泛的汽车文案，而是生成可以直接在直播间照着念、同时兼顾内容价值和互动节奏的汽车直播稿。
