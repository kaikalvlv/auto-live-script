# Auto Live Script — 汽车直播话术生成器

为汽车真人直播设计的话术生成工具。

## 当前功能
- 品牌 / 车型 / 直播时长 / 主题输入
- 停留、评论、关注、留资目标选择
- 粘贴车型资料、行情和自己的原始话术
- 生成直播结构、互动、费用拆解和自然小程序引导
- 一键复制全文
- `PROMPT.md` 内置长篇 AI 直播稿提示词

## V1
`index.html` 可直接浏览器打开，不依赖服务器，也不需要 API Key。当前使用本地规则生成基础稿。

## V2 AI 接入方案
不要把模型 API Key 写在 `index.html` 或提交到 GitHub。正确结构：

浏览器前端 → 自己的服务端 `/api/generate` → AI 模型 API

服务端从环境变量读取 API Key，并使用 `PROMPT.md` 的规则。

建议请求字段：brand、models、duration、topic、goals、style、facts、reference_script。

AI 输出必须是完整可照读直播稿，而不是提纲。

## 长稿策略
60–90分钟稿不要只依赖一次超长生成。建议采用：
1. 先规划整场内容和分钟分配；
2. 分章节生成；
3. 最后统一优化章节衔接和重复；
4. 对用户提供的事实做一致性检查。

## 准确性
汽车行情、补贴、金融方案和配置会变化。模型不得自行虚构实时价格或政策；优先使用用户提供的数据，未确认信息标记为待核实。
